# Smart Expense & Budget Manager

A web-based expense and budget management application developed as a college minor project.

## Current Progress

- Dashboard
- Add Expense
- Edit Expense
- Delete Expense
- Total Expense Calculation
- Monthly Budget
- Remaining Budget
- Budget Progress Bar
- Category-wise Expense Tracking
- Local Storage Persistence
- Responsive Interface

## Technology Used

- React.js
- JavaScript
- Vite
- HTML
- CSS
